AI Video Automation App — V1 Project Document
1. Project Overview

Build a desktop application that allows a user to:

Upload a video
Choose editing options
Automatically process the video
Export a Shorts-ready video

This is Core Version 1 (no Telegram yet).

2. Goals (V1)
Simple UI
Upload video
Apply automated edits
Export final video
Reusable default settings
3. Features (V1)
Required
Upload video file
Crop to Shorts (9:16)
Resize to 1080x1920
Add captions (optional)
Add background music (optional)
Add tint color (optional)
Add channel name watermark
Export processed video
Optional but good for V1
Manual crop slider
Preview frame
Progress bar
Default settings
4. User Flow
User opens app
→ Upload video
→ Select options
→ Click "Process"
→ App processes video
→ Export final video

6. Editing Options Behavior
Crop to Shorts
Center crop
9:16 ratio
Default ON
Captions
Auto generate subtitles
Burn into video
Background Music
Mix at low volume
Loop if shorter than video
Tint
Apply color overlay
Adjustable opacity (default 20%)
Channel Name
Bottom center
Small watermark
Semi transparent
7. Default Settings
Resolution: 1080x1920
FPS: 30
Audio: keep original
Music volume: 20%
Tint opacity: 20%
Font: bold sans-serif
8. Technical Stack (Recommended)
UI: Python GUI
Processing: FFmpeg
Captions: Whisper (optional for V1)
Language: Python
